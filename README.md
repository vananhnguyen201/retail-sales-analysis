# Retail Sales Analysis

## Project Overview

This project analyzes retail sales data using Microsoft Excel, Pivot Tables, and Pivot Charts to identify sales trends, top-performing categories, regions, and customer segments.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Cleaning
- Data Visualization

## Dataset

Retail sales dataset containing:
- Orders
- Products
- Customers
- Regions
- Sales data

## Data Cleaning

During data preparation, several data quality issues were identified:

- Mixed number formats in the Sales column
- Inconsistent decimal separators (.,)
- Some sales values were inflated due to import formatting issues
- Data types were standardized before analysis

A new `Sale_fixed` column was created to normalize sales values before building Pivot Tables and dashboards.

## Business Questions

1. Which category generates the highest revenue?
2. Which region performs best?
3. Which customer segment contributes the most sales?
5. How do sales change over time?

## Dashboard Components

- Sales by Category and Region
- Monthly Sales Trend
- Sales by Customer Segment

## Key Findings

- Technology and Furniture were among the strongest-performing categories.
- Regional sales performance varied significantly.
- A small number of products generated a large portion of total revenue.
- Clear seasonal patterns were visible in monthly sales.
